# Reader's Guide — HelloGitHub

## What this project is

HelloGitHub is a **monthly magazine that shares interesting, beginner-friendly
open-source projects from GitHub**. Each issue collects popular projects,
entry-level projects, tools that make life better, books, learning notes and
enterprise projects — chosen to be easy to start with, so newcomers can feel
the fun of programming and take a first step into the open-source community.
New issues are released on the **28th of each month**.

## How the content is organised

- **Three README editions** at the root, one per language:
  [`README.md`](README.md) (Chinese), [`README_en.md`](README_en.md)
  (English) and [`README_ja.md`](README_ja.md) (Japanese). Each carries an
  introduction and a table linking to every published issue.
- **`content/`** — the magazine archive itself:
  - `HelloGitHub01.md` … `HelloGitHub126.md` — the Chinese edition of each
    monthly issue, numbered in release order (126 issues at the time of
    writing).
  - `content/en/` — the English edition of the issues.
  - `content/contributors.md` — the contributor list.
- **`script/`** — helper scripts used in producing the magazine.

## How to use it

1. Pick your language's README and open the **Content** table.
2. Choose an issue number — start with the latest for what's fresh, or browse
   older issues by topic; each issue is a self-contained list of projects with
   short introductions and links.
3. Follow the project links out to the featured repositories to try them,
   star them, or contribute.
